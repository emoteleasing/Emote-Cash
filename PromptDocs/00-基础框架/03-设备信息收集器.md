# 03. 设备信息收集器（HQTDeviceInfoCollector）

> **实现类**：`HQIOneCaptn/Utils/HQTDeviceInfoCollector.swift`  
> **公共 deviceId**：`HQTNetworkClient.shared.deviceId`（与上传字段 `uuid` / 下单 `serialNo` 同源）  
> **对齐参考**：DeviceTool（`versionCode` / `screenResolution` / `network`）+ `junchages_getUUID` / ATT IDFA 口径  

本文档为**唯一设备信息规格**。按本文实现即可正确产出 `/app/v3/mobile/registerDevice`、`/app/v3/mobile/device` 的设备字典；**禁止**自行发明旧字段名或随机 UUID。

---

## 3.1 目的与入口

| 场景 | 调用 | 端点 |
|------|------|------|
| 登录成功后注册设备 | `collectDeviceInfo(includeWiFiDetails:…, orderId: nil)` | `POST /app/v3/mobile/registerDevice`（`data` **不参与签名**，仅公共参数签名） |
| 下单/抓取上传设备 | `collectDeviceInfoForOrder(orderId:)`（异步，含 Wi‑Fi 尽力采集） | `POST /app/v3/mobile/device`（signed 仅 `orderId`；unsigned = 设备字典） |

- 收集器**只产出设备字典**，不负责通讯录（见 `25-印度手机号规则.md`、`05-数据抓取与通讯录分片.md`）。
- 空字符串最终一律标准化为字面量 **`"null"`**（不是 JSON `null`）。

---

## 3.2 输出约定

- 类型：`[String: String]`（布尔、数字一律字符串化）。
- **仅使用下文「现行字段名」**；旧口径字段名列入 §3.7，返回前必须过滤。
- `orderId`：登录注册无订单 → `"null"`；抓取上传 → 真实订单号字符串。

---

## 3.3 标识字段获取方式（必须严格一致）

### 3.3.1 `idfv`

```text
UIDevice.current.identifierForVendor?.uuidString ?? ""
```

空则最终变为 `"null"`。

### 3.3.2 `uuid`（与公共 `deviceId` / 下单 `serialNo` 同源）

对齐 ObjC **`junchages_getUUID`**：

1. 从 Keychain 读取（service / account 均为项目约定 key，本项目：`com.hqionecaptn.name_password`）。
2. 若无值或空字符串：取当前 **IDFV**，写入 Keychain 后返回。
3. **禁止**每次 `UUID().uuidString` 随机生成；**禁止**与 `idfv` 人为强制取不同值（首次安装时 `uuid` 通常等于 `idfv`，属预期）。
4. 存档格式：与 DeviceTool 一致，优先 `NSKeyedArchiver`；读取时兼容 UTF‑8 明文。
5. Keychain `kSecAttrAccessible`：`AfterFirstUnlock`。
6. 实现：`HQTNetworkClient.loadOrCreatePersistentDeviceId()`；收集器 `uuid = HQTNetworkClient.shared.deviceId`。

### 3.3.3 `idfa`

对齐参考 `idfaString()`：

| 条件 | 上传值 |
|------|--------|
| iOS 14+ 且 `ATTrackingManager.trackingAuthorizationStatus != .authorized` | `"null"` |
| `advertisingIdentifier` 为全 0：`00000000-0000-0000-0000-000000000000`（大小写不敏感） | `"null"` |
| 已授权且非全 0 | `ASIdentifierManager.shared().advertisingIdentifier.uuidString` |

- ATT/Adjust 弹框与初始化编排见 **`24-IDFA与Adjust初始化流程.md`**（`HQTIDFAAdjustCoordinator`）；设备采集**只读**当前授权状态，不在收集器内再弹 ATT。
- `/app/v3/user/info` 的 `adid` 优先 Adjust SDK，与本字段独立。

### 3.3.4 `versionCode`

- 取 `CFBundleShortVersionString`（营销版本，如 `1.0.0`）。
- **不是** `CFBundleVersion` 纯数字 build。
- 空则兜底 `"1.0.0"`。

## 3.4 现行上传字段总表（格式 + 获取）

> 生成代码时：**字段名、分隔符、单位、数字码必须按下表**，不得改回旧名（如 `appVersion`/`networkType`/`deviceUUID`）。

### 3.4.1 基础标识

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `versionCode` | `1.0.0` | `CFBundleShortVersionString` |
| `idfv` | `C242618E-…` | `identifierForVendor` |
| `uuid` | 同 IDFV（首次）或 Keychain 缓存 | §3.3.2 |
| `idfa` | UUID 或 `null` | §3.3.3 |
| `orderId` | 订单号或 `null` | 入参 |

### 3.4.2 内存 / 存储（单位 G，纯数字，可含小数）

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `ramTotal` | `3.75` | `ProcessInfo.physicalMemory` → GB，去尾零 |
| `ramCanUse` | `0.13` | `host_statistics64` free → GB |
| `cashTotal` | `238` | 文件系统 `systemSize` → GB |
| `cashCanUse` | `93` | 文件系统 `systemFreeSize` → GB |

格式化：`String(format: "%.6f")` 后去掉尾部 `0` 与多余小数点；≤0 为 `"0"`。

### 3.4.3 开机 / 电量

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `totalBootTime` | `236209000` | `systemUptime * 1000`（毫秒，整数字符串） |
| `totalBootTimeWake` | 同 `totalBootTime` | iOS 无法区分休眠，与 total 相同 |
| `lastBootTime` | epoch 毫秒 | `(now - uptime) * 1000` |
| `charged` | `true` / `false` | `batteryState` 为 charging/full → true |
| `batteryLevel` | `80` | `batteryLevel * 100` 取整；无效则 `0` |

### 3.4.4 风险标记

| 字段 | 取值 | 获取方式 |
|------|------|----------|
| `debugged` | `true`/`false` | `#if DEBUG` |
| `simulated` | `true`/`false` | `#if targetEnvironment(simulator)` |
| `rooted` | `true`/`false` | 常见越狱路径是否存在 |
| `proxied` | `true`/`false` | 系统代理检测 |
| `isvpn` | `true`/`false` | VPN 接口检测 |

### 3.4.5 系统环境

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `systemVersions` | `26.6.2` | `UIDevice.systemVersion`（注意复数名 `systemVersions`） |
| `defaultLanguage` | `en` | `Locale.current.languageCode` |
| `defaultTimeZone` | `Asia/Shanghai` | `TimeZone.current.identifier` |
| `screenResolution` | `1242-2688` | `(bounds.width*nativeScale)-(bounds.height*nativeScale)`，**用 `-` 分隔**，**全 scale**（勿封顶 2、勿用 `x`） |
| `screenWidth` | `414` | 逻辑点宽 `Int(bounds.width)` |
| `screenHeight` | `896` | 逻辑点高 |
| `screenBrightness` | `69` | `brightness * 100` 取整 |
| `cpuNum` | `6` | `ProcessInfo.processorCount` |
| `deviceType` | `3` | 固定 `"3"`（iOS） |
| `sdkVersion` | `null` | 固定 `"null"`（Android 语义字段） |

### 3.4.6 网络

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `network` | `0`/`1`/`2`/`3`/`4`/`5` | **数字码**（见下表），不是 `wifi` 文案 |
| `wifiSsid` / `wifiName` | SSID 或 `null` | Wi‑Fi 采集；`wifiName` = `wifiSsid` |
| `wifiBssid` | BSSID 或 `null` | 同上 |
| `mac` | 与 `wifiBssid` 相同 | 合并后 `mac = wifiBssid` |

**`network` 数字码（对齐 DeviceTool）：**

| 码 | 含义 |
|----|------|
| `0` | 未知 / 不可达 |
| `1` | WiFi |
| `2` | 2G |
| `3` | 3G |
| `4` | 4G |
| `5` | 5G |

判定：Reachability → WiFi 或 WWAN；WWAN 用 `CTTelephonyNetworkInfo` 无线接入技术映射 2G/3G/4G/5G。

### 3.4.7 设备型号

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `phoneMark` | `iPhone18,3` | `utsname.machine`（硬件标识，**不是**用户设备名 / 营销名） |
| `phoneType` | `xxx's iPhone` | `UIDevice.current.name`（用户设备名） |

> 本项目两字段与常见 Android 示例对调，**禁止写反**。不再上传 `deviceBrand` / `deviceUUID` / `deviceName` / `deviceModel`。

**营销型号映射**（User-Agent `{model}` 等展示用，不写入 `phoneMark`）：由设备信息模块维护 `machine → 营销名` 表，须覆盖至当前最新机型，至少包括：

| machine | 营销名 |
|---------|--------|
| `iPhone17,1`–`17,5` | iPhone 16 Pro / Pro Max / 16 / 16 Plus / 16e |
| `iPhone18,1`–`18,5` | iPhone 17 Pro / Pro Max / 17 / Air / 17e |
| `iPhone19,2` / `19,3` / `19,7` | iPhone 18 Pro / 18 Pro Max |

未知 `iPhone*` / `iPad*` 回落为 `iPhone` / `iPad`；模拟器为 `Simulator`。

### 3.4.8 SIM

| 字段 | 格式示例 | 获取方式 |
|------|----------|----------|
| `simCount` | `0`/`1`/`2` | 有非空 `carrierName` 的卡数 |
| `slotCount` | `0`/`1`/`2` | 可枚举 carrier 条目数，最多 2 |
| `telephony` | 运营商名或 `--` | 卡 1；无则 **`--`**（双横线，不是 `---` / `null`） |
| `telephony2` | 同上 | 卡 2 |

### 3.4.9 媒体占位（iOS 不可用）

| 字段 | 固定值 |
|------|--------|
| `videoInternal` | `-99` |
| `albumFile` | `-99` |
| `imageInternal` | `-99` |

## 3.5 Wi‑Fi 采集策略（必须）

### 3.5.1 版本策略

| iOS 版本 | 策略 |
|---------|------|
| **26+** | **仅** `NEHotspotNetwork.fetchCurrent()`；**禁止** `CNCopyCurrentNetworkInfo` |
| **14–25** | 优先 `fetchCurrent`；失败再降级 `CNCopyCurrentNetworkInfo` |
| **&lt;14** | 仅 `CNCopyCurrentNetworkInfo` |

- `fetchCurrent` 超时 **2s**；主线程等待时须泵 RunLoop（回调也在主线程，直接 `semaphore.wait` 会饿死）。
- 下单场景：`collectDeviceInfoForOrder` 在定位授权允许时再读 Wi‑Fi；若当前为 **Reduced Accuracy**，先 `requestTemporaryFullAccuracyAuthorization(purposeKey: WifiSSID)` 再 `fetchCurrent`（iOS 14+ / 26+ 提高 SSID 可读率）。
- 失败字段写 `"null"`。
- `Info.plist` 需：
  - `NSLocationWhenInUseUsageDescription`
  - `NSLocationTemporaryUsageDescriptionDictionary` → key **`WifiSSID`**（与代码 purposeKey 一致）
- **换 Bundle ID**：entitlements 的 `wifi-info` 与 `WifiSSID` 临时定位说明**不得删除**；须在新 App ID 勾选 Access WiFi Information。改包名流程与 Xcode 闪退规避见 `26-BundleID与工程配置规避.md`。

### 3.5.2 生成约束

1. 不得简化掉版本分支。  
2. iOS 26+ 不得调用旧 CaptiveNetwork 查当前网。  
3. 必须打版本/结果日志便于联调。  
4. 不得因换包名删掉 Wi‑Fi entitlement / `WifiSSID` 配置。

（完整示例代码可参考本文件历史附录或工程 `HQTDeviceInfoCollector` / `HQTWiFiCapture`。）

## 3.7 禁止上传 / 已废弃旧字段名

实现用 `HQTDeviceInfoCollector.excludedUploadFieldKeys` 在返回前过滤。下列 **不得** 出现在 registerDevice / device 的 `data` 中：

### 3.7.1 Android 遗留 / 不采

`batteryTemperature`、`batteryHealth`、`batteryMax`、`cpuMinFrequency`、`cpuMaxFrequency`、`cpuCurrentFrequency`、`cpuModel`、`productionDate`、`imei`、`androidId`、`audioExternal`、`audioInternal`、`videoExternal`

> 登录/下单接口 signed 里的 `imei="null"` 是业务签名字段，**不是**本设备字典字段。

### 3.7.2 旧口径字段名（已改用新名，禁止再传）

| 禁止旧名 | 现行字段 |
|----------|----------|
| `appVersion` | `versionCode` |
| `systemVersion` | `systemVersions` |
| `deviceUUID` | `uuid` |
| `networkType` | `network`（且必须是数字码） |
| `storageCapacity` / `availableStorage` | `cashTotal` / `cashCanUse` |
| `totalMemory` / `availableMemory` | `ramTotal` / `ramCanUse` |
| `runningTime` | `totalBootTime` 等 |
| `chargingStatus` | `charged` |
| `brightness` | `screenBrightness` |
| `screenSize` | `screenWidth` / `screenHeight` + `screenResolution` |
| `language` / `timezone` | `defaultLanguage` / `defaultTimeZone` |
| `proxy` / `vpn` | `proxied` / `isvpn` |
| `deviceBrand` / `household` / `reserve` | 不传 |

## 3.8 联调自检清单

- [ ] `uuid` 来自 Keychain+IDFV，与 `deviceId`/`serialNo` 一致；非随机 UUID。  
- [ ] `idfa`：未授权 ATT 或全 0 → `"null"`。  
- [ ] `versionCode` 为 `x.y.z` 版本名。  
- [ ] `screenResolution` 形如 `1242-2688`（`-`，全 scale）。  
- [ ] `network` 为 `0`–`5`，不是 `wifi`。  
- [ ] `telephony`/`telephony2` 空值为 `--`。  
- [ ] 请求 JSON **无** §3.7 禁止 key。  
- [ ] 空串已变为 `"null"`。  
- [ ] 抓取上传走 `collectDeviceInfoForOrder`；进入抓取即展示 loading（见 `05-数据抓取与通讯录分片.md`）。
