# 基础框架 Prompt 模板（直接使用）

## 使用说明

用于按 **HQEigFina** 仓库内基础框架文档生成或重构网络、弹框、启动、通知、埋点、设备采集等能力。请替换：

- `{架构模式}`：MVC / MVVM / MVP  
- `{字体工具类名称}`：无 或 实际类名  
- `{布局工具类名称}`：无 或 实际类名  
- `{HUD工具类名称}`：必填  
- `{网络请求工具类名称}`：无 或 实际类名  
- `{布局方式}`：SnapKit / Auto Layout / Frame 等  
- `{页面设计图链接或图片路径}`：无 UI 单页时可填 **无**  

---
