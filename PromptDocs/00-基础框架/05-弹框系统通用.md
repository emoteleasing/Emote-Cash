# 05. 弹框系统通用规范（BaseDialog / HQTUnifiedDialogs）

## 5.1 原则
- 所有业务弹框继承 `HQTBaseDialog`，样式与实现集中在 **`HQTUnifiedDialogs.swift`**。
- 对外统一入口：**`HQTDialogs`**（六类弹框 + 统一样式 `HQTUnifiedDialogStyle`）。
- 背景点击关闭默认 **false**；仅业务明确要求时开启。

## 5.2 六类弹框（必须按类选用）

| 类型 | 类 / API | 展示位置 | 典型场景 |
|------|----------|----------|----------|
| **1. 带标题** | `HQTDialogs.showTitle` → `HQTStandardBottomDialog` | 默认底部卡片；可 `placement: .center` | 退出登录、待提现、注销、处理中订单 |
| **2. 不带标题** | `HQTDialogs.showBody` → `HQTStandardBottomDialog` | 默认底部；可居中 + `footerView` | 权限二次引导 b2/b3/b4–b6、官网说明+URL 条 |
| **3. 带图标** | `HQTDialogs.showIcon` / `HQTIconDialog` | 底部卡片 | 版本更新（火箭图 `ic_upgrade`） |
| **4. 数据抓取** | `HQTDialogs.makeScrapeProgress()` → `HQTScrapeProgressDialog` | **底部卡片**（距安全区底 **100pt**） | 下单/订单详情抓取进度 Under review；步骤区 Apply/Reviewed/Received 间 **17×4** 白色分割线，文字距内嵌底 **13pt**、距分割线 **15pt** |
| **5. 好评引导** | `HQTDialogs.showRatingGuide` → `HQTRatingGuideDialog` | **居中** | 申请/订单详情 `successfulGoBack` 后星级引导；低星接 `showRatingThankYou` |
| **6. 首页复借** | `HQTDialogs.showReloan` → `HQTReloanGuideDialog` | 底部卡片 | 首页复借：金额 + 祝贺文案 + 产品行 + Apply Now（右上角 X 关闭） |

### 5.2.1 统一样式要素
- 深色底 `#0F172A` + 底图 `tk_bg`（底部卡片仅顶部圆角）
- 关闭 `ic_Icon／X`（可隐藏）
- 主按钮胶囊 + 青色底 + 箭头 `tk_jt`
- 标题白色 16pt Bold；正文 `#94A3B8` 14pt
- 内嵌条背景 `#121C2E`（官网 URL、抓取进度、**星级面板** 等）

### 5.2.2 好评引导专用
- 五星条置于 `#121C2E` 内嵌面板；选中星 `accentColor`，未选 `#475569`
- ≥4 星：`SKStoreReviewController` 后关闭并回调 `onFinished`
- 1–3 星：关闭后 `HQTDialogs.showRatingThankYou`（复用第 1 类带标题居中）
- 频控：`HQTProductApplyFeedbackGuide.shouldShowRating` + `HQTRatingGuideDialog.shownOnceKey`

### 5.2.3 兼容类型名（勿在新代码使用）
- `HQTFunctionalDialogView` = `HQTStandardBottomDialog`
- `HQTVersionUpdateDialogView` = `HQTIconDialog`
- 旧名兼容见 `HQTRatingDialogCompat.swift`（`HQTProductRatingGuideDialog.present` 等）
- `HQTFunctionalDialogStyle` = `HQTUnifiedDialogStyle`

## 5.3 调用示例

```swift
// 5. 好评引导
HQTDialogs.showRatingGuide(in: hostView) {
    // pop / 刷新列表等
}

// 低星感谢（一般由好评引导内部调用）
HQTDialogs.showRatingThankYou(in: hostView, onFinished: { })
```

## 5.4 业务封装（推荐）
- 我的页：`HQTMeDialogs` → `showTitle`
- 权限：`HQTPermissionSecondaryDialog` → `showBody`
- 申请/订单详情 H5：`successfulGoBack` → `showRatingGuide`（经 `HQTProductApplyFeedbackGuide` 判断）
- 版本：`HQTVersionUpdateDialog` → `showIcon`

## 5.5 弹框管理器
- `HQTDialogManager`：队列与冲突控制（按需接入 `show`）。

## 5.6 新增弹框检查清单
1. 属于五类中的哪一类？
2. 是否应走 `HQTDialogs` 而非新建样式？
3. 文案来源、按钮语义、是否允许背景关闭、埋点
