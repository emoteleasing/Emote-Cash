# 开发顺序（按步骤做，做完打勾）

用法与 **Prompts参考/开发顺序.md** 一致；下列路径均相对于 **`PromptDocs/PromptDocs/`**。

每做一步：

1. 确认本步对应的 **Prompt 模板文件**、**需求文档**、**页面设计图.txt 中的 key**。  
2. 打开 Prompt 模板，用 `项目配置.txt` 替换占位符，填入设计图路径。  
3. 将完整 Prompt 发给 AI（建议附加 `@` 需求文档 `.md`）。  
4. 接入并验证后，在本步骤前打勾。

---

## 第一步：项目配置（只做一次）

- [ ] 填好 `项目配置.txt`（架构、布局、四个工具类）
- [ ] 后续步骤沿用同一份配置

---

## 第二步：设计图（每页开发前准备）

- [ ] 在 `页面设计图.txt` 中为下表中的 **设计图 key** 写好路径（Figma/图片均可）
