## 核心特性（与 Prompts参考 对齐）

- **需求文档**：各 `NN-xxx.md` 为业务与接口的单一事实来源  
- **Prompt 模板**：各 `NN-xxx-Prompt模板-直接使用.md` 内含项目配置占位符 + 引用需求文档路径，可复制整段使用  
- **配置复用**：`项目配置.txt` 中的架构、布局、工具类名在每一步重复填入 `{占位符}`  
- **设计图**：Figma 链接、图片 URL 或本地路径，填入模板中的 `{页面设计图链接或图片路径}`（无界面步骤可填「无」）

## 使用流程

### 1. 准备信息（一次性）

在 `项目配置.txt` 中填写（没有的填「无」，HUD 必填）：

- 架构模式、布局方式、字体/布局/HUD/网络工具类名称  

在 `页面设计图.txt` 中为每个模块写一行：`模块名 = 设计图路径`（与 [开发顺序.md](./开发顺序.md) 中的 key 一致）。

### 2. 选择模块

- 基础框架 → `00-基础框架/基础框架-Prompt模板-直接使用.md`  
- 具体页面 → `10-页面功能及开发流程/` 下对应的 `NN-xxx-Prompt模板-直接使用.md`  

### 3. 填写并发送

复制模板中「Prompt 内容」代码块内的全文，将所有 `{占位符}` 替换为实际值，将完整 Prompt 发给 Cursor / ChatGPT / Claude 等。

### 4. 接入与验证

合并生成代码、联调接口与埋点，对照需求文档验收。

## 与 Prompts参考 的关系

- **Prompts参考**：按「模块文件夹」拆分的通用 iOS Prompt 库（含大量独立需求文档与模板）。  
- **PromptDocs**：**HQEigFina 项目** 的页面与框架规格；已按参考补齐 **README / 快速开始 / 简易工作流 / 开发顺序 / 项目配置 / 页面设计图 / 各页 Prompt模板**，便于同一套工作流在两套文档间切换。

如有问题，优先查阅对应模块的 `NN-xxx.md` 需求文档与 `NN-xxx-Prompt模板-直接使用.md` 中的说明。
