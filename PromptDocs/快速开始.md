# 快速开始（约 5 分钟）

**更省事**：只要「设计图路径 + 最少配置、按步开发」→ 请看 [简易工作流.md](./简易工作流.md)，配合 `项目配置.txt`、`页面设计图.txt`、[开发顺序.md](./开发顺序.md)。

---

## 核心流程

```
准备项目配置与设计图 → 打开对应 Prompt 模板 → 替换占位符 → 发给 AI → 接入工程验证
```

---

## 第一步：准备信息

### 项目配置（建议只做一次）

编辑仓库内 [项目配置.txt](./项目配置.txt)：

- 架构模式、布局方式、字体/布局/HUD/网络工具类（无则填「无」，HUD 必填）

### UI 设计图

- Figma：`https://www.figma.com/design/...`  
- 或本地/网络图片路径  

在 [页面设计图.txt](./页面设计图.txt) 里为当前模块写一行 key（与 [开发顺序.md](./开发顺序.md) 表格一致）。

---

## 第二步：使用 Prompt

1. 在 [开发顺序.md](./开发顺序.md) 中找到当前步骤对应的 **Prompt 模板路径**。  
2. 打开该文件，复制 **「## Prompt 内容」** 下方代码围栏内的全部文字。  
3. 将 `{架构模式}`、`{布局方式}`、`{HUD工具类名称}` 等替换为 `项目配置.txt` 中的值。  
4. 将 `{页面设计图链接或图片路径}` 替换为 `页面设计图.txt` 中该模块的路径（基础框架类步骤可填「无」）。  
5. 将完整内容发给 AI；若使用 Cursor，可用 `@文件` 附加同目录需求文档 `NN-xxx.md` 便于模型读取。

---

## 第三步：验证

1. 将生成代码接入目标工程  
2. 对照 `NN-xxx.md` 检查接口顺序、字段与状态机  
3. 自测埋点、弹框优先级等与文档一致
