# 11. 我的模块 — 快速开始（提示词与实现说明）

本文档整理「我的」页的产品提示词、接口与实现索引，与 `11-个人中心与关于我们.md` 配合使用。

## 一、可直接复制的需求提示词（给 AI / 评审）

```
我的页面 UI 按 Pencil 选中的「我的」实现，使用 UITableView。业务逻辑如下：

1、顶部信息模块：
进入我的页面请求 /app/v3/user/info，data 参数：
- adid string（Adjust ID，可选；选填字段不参与签名时可按项目约定）
- adjustID（可选）
- firebaseInstanceId string（firebase 上报前端得到的 firebase_instance_id）
将返回内容中的手机号、姓名同步展示。若用户未完成 KYC：不展示姓名一栏或展示 App 名（与 UI 一致）。

2、银行卡：点击进入银行卡列表页。

3、Contact Us：进入公共 Web 页，导航标题 Contact Us，链接取配置接口 contactHref。

4、Privacy policy：进入公共 Web 页，导航标题 Privacy policy，链接取配置接口 policyHref。

5、Terms of the loan：进入公共 Web 页，导航标题 Terms of the loan，链接取配置接口 conditionsHref。

6、Feedback：进入问题反馈页。

7、Repayment instructions：原生页，导航同 Feedback；ScrollView 上两张可复制白卡片（`appEmail` / `officialWebsiteUrl`）+ 下一大卡片三段英文说明；整卡复制 Toast「Copied to clipboard」/「No content to copy」。详见 `11-个人中心与关于我们.md` 的 **11.7**。

8、About：进入关于我们页（首页入口）；UI 与注销流程见 `11-个人中心与关于我们.md` **11.3** / **11.4**。

9、Official Website：push 原生页 `HQITOfficialWebsiteViewController`（导航同 Feedback）；浅黄提示卡 + 白 URL 卡展示 `officialWebsiteUrl`；仅复制按钮复制，成功「Copied to clipboard」、无内容「No content to copy」。详见 `11-个人中心与关于我们.md` 的 **11.8**。

10、Sign out：点击弹出退出确认框（样式按 UI），文案：Are you sure to sign out your account？确认后跳转登录页并清空用户信息等。
```

## 二、工程实现索引（代码）

| 能力 | 说明 |
|------|------|
| 我的主页 | `Home/Mine/HQNMineViewController.m`：UITableView + 头部信息区；进入时请求 `/app/v3/user/info`；`adid` / `firebaseInstanceId` 从 `NSUserDefaults` 键 `HQE_ADJUST_ADID`、`HQE_FIREBASE_INSTANCE_ID` 读取（有 adid 时才带 firebaseInstanceId，与接口清单一致）；`userStatus == 10` 视为未完成 KYC，姓名区展示 `CFBundleDisplayName`。 |
| 银行卡列表 | `HQITBankAccountViewController`：并行 `/app/v3/bankcard/list` + `/app/v3/user/info`；有卡取首条，卡片展示 **Bank Account / accountNo / accountName**（不展示 IFSC）；`payAccountModifySwitch` 控制修改入口；见 `09-银行卡模块.md`。 |
| 问题反馈 | `HQITFeedbackViewController`：原生表单；上传 `/app/v3/sys/upload`；提交 `/app/v3/user/problemFeedback`（`description`/`contactWay`/`pictureUrl` unsigned）；见 `10-反馈模块.md`。 |
| 还款须知 | `Me/HQITRepaymentInstructionsViewController`：Feedback 导航 + 两张可复制卡 + 三段说明卡；`appEmail` / `officialWebsiteUrl` 来自配置。 |
| 官网页 | `Me/HQITOfficialWebsiteViewController`：Feedback 导航 + 提示卡 + URL 卡 + 复制按钮；`officialWebsiteUrl` 配置；Toast 英文（见 **11.8**）。 |
| Web 统一页 | `Base/HQEWebViewController` + `+ controllerWithHrefConfigKey:pageTitle:`；安全区下展示 URL 条 + `WKWebView`；标准导航标题；无效 URL 时 Toast：`The system is busy. Please try again in 2 minutes.` |
| 退出登录 | `HQESessionManager clearLoginSession` + `HQNAppShell installRootViewControllerInWindow:`；弹框文案 `Are you sure to sign out your account?`。 |
| 关于我们 | `HQITAboutViewController`：EMI 式导航 + 信息卡/说明卡 + Delete Account；注销 `/app/v3/auth/close`；见 `11-个人中心与关于我们.md` **11.3** / **11.4**。 |

## 三、配置字段与导航标题对照

| 菜单 | 配置键 | Web 导航标题 |
|------|--------|----------------|
| Contact Us | contactHref | Contact Us |
| Privacy policy | policyHref | Privacy Policy |
| Terms of the loan | conditionsHref | Terms of the Loan |
| Official Website | officialWebsiteUrl | （原生页展示 + 复制按钮复制，不打开 Web） |

## 四、与 Pencil 对齐要点

- 页背景色接近 `#b1cdba`；头像区圆形容器描边；手机号浅绿底 `#f2f5e4`、描边 `#6daa80`。
- 菜单为白底圆角行 + 右侧 chevron；Sign out 为红色文案。
- 外层「Menu」绿描边容器可在后续迭代用 section 背景或容器视图加强。
