# 00. 全流程字段与判断总表（归档规则同步版）

## A. 首页关键判断
- 接口顺序：
  - `/app/v3/user/suphome` -> `/app/v3/user/info` -> `/app/v3/app/versionV2`（首页 **不** 拉 `product/list`）
- `userStatus` 路由：
  - 10：KYC
  - 32：待提现
  - 其它：产品列表 + 复借检查
- **自动下单 / 精准推荐**（完整见 `31-精准推荐与自动下单.md`；首页入口见 `02` §2.7）：`hasOrder==0` + `userStatus==20` + `firstLoanOptionLine==system`（忽略大小写）；不依赖 `product/list`
  - KYC 完成回首页流水线结束后启动；或自动下单态下点首页 Apply
  - 链路：`dcRecommend`（10s 超时→4102007 页）→ 全部产品最大额+最高期 → `userSubmitDcUpgrade` → 抓取 → 精准推荐成功页
  - `termV3` → 最高额+最低期 → 定位 → `userSubmitV3`（不传 `orderType`）→ 抓取 → 成功页；启动时跳过本轮弹框链
- 提示箭头显示状态：
  - `10, 30, 32, 41, 80, 81`
  - `51`：**仅** `rejectH5` 已配置时显示（见 §I）
- 弹框优先级：
  - 版本更新 > 待提现 > 复借 > 通知权限（每日一次 b15 引导；详见 `06-通知与推送能力实现.md`、`25-推送与通知权限-Prompt模板-直接使用.md`）
  - 若本轮已启动自动下单，则跳过弹框链

## B. 产品申请页字段绑定
- 产品区：
  - `productLogo`, `productName`, 当前金额（或最高金额）
- 额度/期限：
  - `amountDetailList`（单/多额度）
  - `termDetailList`（单/多期限）
- 明细区：
  - Loan term: `showTerm`
  - Amount received: `receiptAmount`（缺失可兜底）
  - Service fee: `feeAmount`
  - Interest: `taxAmount`
  - Loan time: `loanTime`
  - Due time: `dueTime`
- 还款计划：
  - `productTermItemList` + 提示文案字段（接口兼容名）

## C. 下单前后判断
- 定位强抓判断：
  - `retrieveMobileContact == 1` 或 `== 2`：强抓
  - `retrieveMobileContact == 0`（及其它）：非强抓
- 下单接口：
  - `/app/v3/order/userSubmitV3`
  - signed：`productId/loanAmount/longitude/latitude/imei/serialNo`
  - unsigned：`showTerm/orderType/bankCardBindId?`
- 复借口径：
  - `orderType = 1`

## D. 抓取流程判断
- 顺序：
  - `/app/v3/mobile/device` -> `/app/v3/mobile/contact`(分片) -> `/app/v3/order/ready`
- allowContact：
  - 空串=已完全授权；2=未授权（含 iOS 18+ Limited，按未授权处理，不上传通讯录）
- 强抓通讯录首次拒绝规则（当前生效，**含 iOS 18+ Limited 按未授权**）：
  - 本次流程直接结束，不立即展示二次自定义权限弹框
  - 下一次进入流程时（状态 denied/restricted/limited）再展示二次弹框

## E. 订单列表与详情判断
- 列表：
  - `/app/v3/order/list` 分四个 orderStatus 请求
  - 状态码映射为展示名与 badge 资源，不直接显示数字状态码
  - **`status == 31`**：展示 *Reject*；点击跳转见 §I（拒量 H5 或订单详情 H5）
- 详情：
  - `/app/v3/order/detailV2`（普通）
  - `/app/v3/order/withdrawn/detail`（待提现）
- 状态驱动按钮：
  - 10 Submit
  - 36 Change bank account
  - 60 Repay + Defer
  - 61 Repay
- 详情字段显隐：
  - 见 `07-订单详情与待提现.md` 的显隐判断小节

## F. 银行卡模块判断
- 列表空态：列表为空展示 emptyView
- 添加拦截：
  - `userStatus == 10` -> 文案 `n53`
- 禁编辑提示：
  - 文案 `n54`
- 新增/编辑提交：
  - `defaultFlag + kycCommitItemList (+recordId)`

## G. KYC 判断
- 多步流程：`/app/v3/kyc/status` → `kycList` 按 `kycSort` 逐步完成（personal/work/credit/identity/pan/pay_account/emergency/liveness 等）
- 省市联动：先省后市；省变更清空市
- 紧急联系人：关系必填、手机号标准化并去重；姓名/电话可系统通讯录选取并回填同组
  - 非全空但缺 name/phone/relationship → `m19` 或 `m20`（`KT_CONTACTNO` 按序号替换）
  - 手机号不合法 → `m14`；重复 → `m13`；email 非空格式错 → `m12`
  - 组内全空则跳过该校验
- 活体：前置相机自拍，禁相册；接口 `/app/v3/kyc/liveness/silent`
- Aadhaar/PAN 图上传失败码 `6212011`/`6212201` → 认证失败弹框并清空对应图片
- 输入限制：印度手机号 10/11 位规则；字段长度见各步 init；可选自动跳转下一空字段

## I. 拒量（rejectH5）门控总表

> 完整说明：`09-拒量功能.md`。配置字段 **`rejectH5`**；判断 **`HQE_isRejectH5Configured`**。

| 入口 | 触发条件 | 已配置 `rejectH5` | 未配置 `rejectH5` |
|------|----------|-------------------|-------------------|
| 首页提示词 | `userStatus == 51` | 显示箭头；点击 → 拒量 H5 | 无箭头；点击无反应 |
| 首页产品 | `termV3` → `6234303` | 直接拒量 H5，不弹框 | 处理中弹框（`resultMsg`），不跳转 |
| 订单列表 | 点击 `status == 31` | 拒量 H5 | 订单详情 H5 |

- `6230002` / `6230003`：与拒量配置无关；弹框 + Know More → 订单详情（`02-首页Loan.md` §2.5）。
- 拒量 H5：`rejectData` 注入、`iosHandler` 消息 `thirdUrl=…&type=…`、外链前埋点 **502**。

## H. user/info 与 adid 判断
- Adjust 已注册且有 `adjustToken`：
  - `/app/v3/user/info` 优先上传 `adid`
- 无 adid：
  - 不上传无意义占位字段（`firebaseInstanceId/smsSwitch` 按当前规则处理）
