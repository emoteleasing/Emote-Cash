# 订单详情与待提现 Prompt 模板（直接使用）

## 使用说明

与 **Prompts参考** 中各模块的 `Prompt模板-直接使用.md` 用法一致：替换下列占位符后，复制「Prompt 内容」代码块全文发给 AI。

- `{架构模式}` / `{布局方式}` / 各工具类名：来自 `PromptDocs/PromptDocs/项目配置.txt`（与 README 同级）
- `{页面设计图链接或图片路径}`：来自 `页面设计图.txt` 中与本模块对应的 key（无界面可填 **无**）

**需求文档（业务唯一来源）**：与本文件同目录的 `07-订单详情与待提现.md`  
（在 Cursor 中建议用 `@` 引用该文件全文。）

## 四、输出要求

- 代码风格、目录分层、类前缀与 `00-项目基础规范.md` 一致。
- 复用工程已有网络层、弹框、HUD、防连点等能力，禁止平行重复实现。
- 订单详情与待提现详情必须拆分为两个页面类（普通详情页 / 待提现详情页），禁止继续用单页模式开关混传。

- 提现成功后必须展示统一通用弹框：图标 `make_pic_su`、标题 `Success!`、按钮 `Confirm`；点击后返回上一页并刷新数据。
- 订单详情还款/展期进入的 Web 页面必须实现 `decidePolicyFor navigationAction`：`http/https` 放行；非 `http` 用 `UIApplication.shared.open` 拉起外部 App，拉起失败 toast `Please install the app first.`，并取消当前导航。
- 说明主要改动文件与自测要点。

请根据以上要求生成或修改代码。
