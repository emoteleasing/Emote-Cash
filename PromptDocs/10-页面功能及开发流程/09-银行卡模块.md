# 09. 银行卡模块（Bank Account · 印度）

> **用途**：按本文档即可完整实现本工程**印度市场**银行卡展示与修改。仅描述功能、流程、校验与接口口径；**不含具体代码**。  
> 工程实现索引：`HQITwoFncesd/Bank/`（`HQITBankAccountViewController` / `HQITBankAccountEditViewController`）。

---

## 9.1 页面目标

1. **银行卡展示页**：有卡展示卡片信息；无卡展示空态。
2. **修改页**：UI/字段配置同 KYC 收款账户（`pay_account`）；提交走【修改银行卡】接口。

---

## 9.2 入口

| 入口 | 行为 |
|------|------|
| 首页 Bank Account | push `HQITBankAccountViewController` |
| 其他业务需改卡 | 同样进入展示页，由 `payAccountModifySwitch` 决定能否进修改页 |

---

## 9.3 展示页

### 9.3.1 进入与并行请求

进入页（含 `viewWillAppear` 刷新）并行请求：

| 接口 | 用途 |
|------|------|
| `POST /app/v3/bankcard/list` | 银行卡列表 |
| `POST /app/v3/user/info` | 取 `payAccountModifySwitch` |

可用 `DispatchGroup` / 计数收齐后统一刷新 UI。列表失败 Toast；开关失败视为不可修改。

### 9.3.2 有卡 / 无卡

| 条件 | UI |
|------|----|
| `bankCardList` 有值 | 取**第一个**展示卡片 + 提示语 |
| 列表为空 | 空态（`no_image` + **No bank account**）；**不展示**修改按钮；**不可**进修改页 |

### 9.3.3 卡片字段映射（以本产品 UI 图为准）

背景资源：`bank_bg`；修改图标：`edit_icon`。

| 区域 | 展示 | 数据来源 |
|------|------|----------|
| 左上 | 银行卡图标 + 文案 **Bank Account**（写死） | — |
| 右上 | 修改铅笔按钮 | `payAccountModifySwitch` 控制显隐 |
| 中部标题 | **Bank Account Number**（写死） | — |
| 中部卡号 | 四位一组加空格 | **`accountNo`** |
| 底部姓名 | 大写持卡人姓名 | **`accountName`** |

> 注：列表接口仍返回 `bankCode`（IFSC），修改页回填/提交使用；**展示页卡片不展示 IFSC**。

提示语文案（写死，与 UI 一致）：

> Clicking the bank card logo, you can modify the information. But when your loan order is under review, you can not modify bank account information.

### 9.3.4 修改入口（`payAccountModifySwitch`）

来自 `/app/v3/user/info`：

| `payAccountModifySwitch` | 行为 |
|--------------------------|------|
| `"on"` / `"1"` / `"true"`（大小写不敏感）且**有卡** | 显示修改按钮；**点击整张银行卡区域**均可进修改页 |
| 其他 / 无卡 | 隐藏修改按钮；卡片不可点进修改页 |

---

## 9.4 修改页（同 KYC 支付账号，提交接口不同）

### 9.4.1 进入与布局

1. 进入后请求 **`POST /app/v3/kyc/init`**，`signedData.kycId = "pay_account"`。
2. 按返回 `kycItemList`（兼容 `itemList` / `list`）排序布局；页面 UI 结构可写死（白卡 + 字段栈 + 底栏 Submit），字段内容跟 init。
3. **自动回填**当前绑卡信息：
   - `ifsc` / `bank_code` ← `bankCode`
   - `account_no` ← `accountNo`
   - `account_no_verify` ← `accountNo`（需二次输入确认）
   - `account_name` / `name` ← `accountName`（只读）
   - `credit_card` ← `creditCard`（可选）
4. IFSC 支持手动输入 + **Find IFSC** 子页（复用 KYC IFSC 四级联动）。
5. 校验同 KYC 收款账户（必填、`k60` 两次卡号一致、`credit_card` 仅非空时 regex）。
6. 返回键：**直接 pop**（不做 KYC 退出确认）。

### 9.4.2 提交：`POST /app/v3/bankcard/modify`

| 字段 | 归属 | 取值 |
|------|------|------|
| `accountType` | **signed** | 固定 `"unknown"` |
| `bankCode` | **signed** | IFSC（表单 ifsc） |
| `accountNo` | **signed** | 银行卡号 |
| `accountNoVerify` | unsigned | 银行卡号确认 |
| `creditCard` | unsigned | 信用卡号；未填传 `""` |
| `accountName` | unsigned（可选） | 有值时回传姓名 |

成功后 pop 回展示页；展示页 `viewWillAppear` 重新拉列表刷新。

---

## 9.5 与 KYC 收款账户的差异对照

| 项 | KYC `pay_account` | 本模块修改页 |
|----|-------------------|--------------|
| 字段配置 | `/app/v3/kyc/init` | 同左，`kycId=pay_account` |
| 回填 | init 预填 / user/info 姓名 | **绑卡信息**强制回填 |
| 提交 | `/app/v3/kyc/commit` + `kycCommitItemList` | `/app/v3/bankcard/modify` 扁平字段 |
| 成功后 | KYC 导航下一步 | pop + 刷新列表 |
| 返回 | 退出确认弹框 | 直接返回 |

## 9.7 自测清单

- [ ] 有卡：左上 Bank Account、中部卡号、底部姓名、提示语；右上修改按钮（开关 on 时）
- [ ] 无卡：仅空态，无修改入口
- [ ] `payAccountModifySwitch=on`：改按钮可见，点卡片进修改页
- [ ] 开关非 on：无改按钮，点卡片不跳转
- [ ] 修改页自动回填（含 bankCode/IFSC）；两次卡号不一致拦截
- [ ] 提交 `accountType=unknown`，空信用卡传 `""`
- [ ] 提交成功返回列表并刷新
