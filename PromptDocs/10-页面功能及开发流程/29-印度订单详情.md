# 29. 印度订单详情（Loan information）

> 实现类：`Order/HQITOrderDetailViewController` + `HQITOrderDetailViewModel`  
> UI 以设计稿「Loan information」为准；功能以本页规则为准。

---

## 29.1 页面目标

展示单笔订单完整详情：产品信息、银行卡、金额摘要、按 `orderStatus` 的明细字段、描述文案，以及按 `orderStatus` + `ifExtension` 的底部操作。

同一接口支持：

| 入口 | orderId | productId |
|------|---------|-----------|
| 产品列表 / Know More | `"1"` | 必传 |
| 历史订单列表 | 真实 orderId | 按需 |

---

## 29.2 接口

- **path**：`/app/v3/order/detailV2`
- **signed**：`orderId`
- **unsigned**：`appType` 固定 `"DC"`；`productId`（产品入口必传）
- **Loading**：请求前展示；结束 dismiss；失败 Toast

响应 `data` 含 `product`、`bankCard`、`orderDetail`、`isWillingRepay` 等。

---

## 29.3 UI 结构（设计稿）

- **导航**：同 Feedback / 下单页（`loan_bg` + `back_icon` 36 + 标题 **Loan information** Regular 14 白字）；**禁止左滑返回**。
- **产品卡**（白卡圆角 16）：Logo + 产品名 + 状态徽标；下方 **Loan amount**；若 `EMIs > 0` 右侧展示 **EMIs**（`{n} EMIS`）。
- **银行卡卡**（白卡）：`bank_icon` + 掩码账号；无有效账号则整块不展示。
- **明细卡**（白卡）：左灰标题 / 右 `#333333` Medium 值；`Amount received` / `Service fee` / `Interest` 带问号，点击 Toast 说明（与下单页一致）。
- **提示卡**：浅黄底 + `with_icon`；主文案按状态；60/61 追加 UPI 第二段。
- **底部按钮**：直接放在页面上（无额外底栏容器），距屏幕底 **32**；双按钮时左 **Defer**（白底橙边）右 **Repay**（`button_bg`）。

---

## 29.4 公共区块

### A. 产品

- 名称：`product.productName`
- Logo：`product.productLogo`（空用占位）

### B. 银行卡

- 账号：`bankCard.accountNo`（掩码展示）
- 无有效账号：不展示整块

### C. 金额摘要

| 标题 | 字段 |
|------|------|
| Loan amount | `orderDetail.loanAmount`（空 → `-`） |

### D. EMI（`orderDetail.EMIs > 0`）

- 产品卡右侧展示 `EMIs` 文案
- 明细列表顶部追加：

| 标题 | 字段 |
|------|------|
| 1st EMI Date | `EMIRepayDate`（空 → `-`） |
| EMI Amount | `EMIAmount`（空 → `-`，带 ₹） |

**全状态不展示** `repayExtensionFeeAmount`（Deferment charge）。

---

## 29.5 明细字段白名单（按 orderStatus）

仅展示表内字段，按自上而下顺序。路径均在 `orderDetail`。

### 10 / 30 / 31 / 32 / 36 / 50 / 99（及其它未列状态，同 32）

Amount received → Interest → Service fee → GST → Date of application → Due date

### 60 — Pending Repayment / Repayment Due

Amount received → Interest → Service fee → GST → Payment date → Due date → Total repayment → Amount of deduction → Amount repaid → Amount due

### 61 — Overdue

同上，并在 Due date 后增加 **Late charge**（`penaltyAmount`）

### 70 — Pay off

Amount received → Interest → Service fee → GST → Payment date → Due date → Total repayment → Amount of deduction → Amount repaid → Repayment date

---

## 29.6 展示规则

| 类型 | 字段 | 规则 |
|------|------|------|
| 固定 | receiptAmount / feeAmount / taxAmount / dueDate | 列入白名单则必显；空 → `-` |
| 固定 | payoutDate（Payment date） | 仅 60/61/70；空 → `-` |
| 固定 | applyDate | 非 60/61/70；空 → `-` |
| 条件 | interestAmount | 始终展示 |
| 条件 | penaltyAmount | 仅 61；非空且 ≠ 0 |
| 条件 | total / reduction / already | 非 10/30/31/36/50/99；非空且 ≠ 0 |
| 条件 | shouldRepaymentAmount | 同上，且 **reduction 与 already 不同时均为空**（二者都空则不展示 Amount due） |
| 条件 | repaymentDate | 仅 70；非空才展示 |
| 不展示 | repayExtensionFeeAmount | 全状态 |

| 50 | d11 | Your loan application has been approved. The loan will be disbursed to your account shortly. Please keep an eye on your account. |

`UPI is valid for 15 minutes. To avoid your loss, please use the new link generated by the repayment button to repay.`

## 29.8 底部按钮

| 条件 | 按钮 |
|------|------|
| status == 10 | Continue submitting |
| status == 32 | Withdraw |
| status == 36 | Change Bank Account |
| status == 60 且 ifExtension == `"1"` | Defer + Repay |
| status == 60 且 ifExtension != `"1"` | Repay |
| status == 61 | Repay |
| 其它 | 无按钮 |

### 点击逻辑

- **通用**：Loading、失败 Toast、防连点；业务 orderId 优先 `orderDetail.orderId`，否则入参（入参为 `"1"` 且无详情 id → Toast `Order ID is required`）。
- **Repay**：`/app/v3/order/repay/connect`；signed `orderId`；unsigned `periodNoList: ["1"]` → `data.connect`（http/https）→ `HQITPaymentWebViewController` 标题 Repay。
- **Defer**：`/app/v3/order/repay/extension`；同上 → 标题 Defer。
- **无有效 connect**：Toast `No payment link available` / `Invalid link`。
- **Change Bank Account**：push `HQITBankAccountEditViewController`（页内自行拉 list + user/info）。
- **Withdraw / Continue submitting**：流程页待接（当前 Toast 占位）。
