# 13. 下单成功与好评引导（Success -> Rating Guidance）

## 13.1 页面目标
- 在订单成功抓取完成后展示“订单成功”弹窗。
- 按配置决定是否展示好评引导流程，并保证安装周期内只展示一次。

## 13.2 触发条件
- 通讯录分片与 `/app/v3/order/ready` 成功后进入成功与好评流程。
- H5 `successfulGoBack` / `successfulGoFeedback`（产品申请页、订单详情页共用 `HQEProductApplyWebViewController`）。

## 13.2.1 页面停留与返回（产品申请 / 订单详情 H5）

- **禁止**在展示好评前先 `popToRoot` 或离开当前 H5；好评弹层叠在当前 WebView 之上。
- **不展示好评**（`feedbackGuidance=0` 或本安装周期已展示过等）：收到成功消息后**立即**执行离开当前页（下单申请 `popViewController` 一层；订单详情 `pop` + `HQE_orderDetailDidCloseBlock` 刷新列表）。
- **展示好评**时，仅在下列时机离开当前页：
  - 用户点右上角 **关闭（X）**（等同取消）；
  - 提交星级 **≥ 4**：调起系统评分后返回上一页；
  - 提交星级 **< 4**：感谢弹框（`HQTProductRatingThankYouDialog`）点 **Confirm** 后返回上一页。
- 复借成功后的好评（首页 Presenter）不在本节 H5 容器内，规则见 `08-复借流程.md`。

## 13.3 配置：feedbackGuidance
- `0`：不展示好评流程
- `1`：所有用户都展示（在满足展示条件时）
- `2`：仅老客展示（需要判断用户类型是否为老客口径）

## 13.4 好评展示次数控制
- 安装周期内只展示一次：
  - 只要好评弹框出现过（无论点星、关闭、提交），到卸载重装前都不再展示。

## 13.5 交互规则
- 用户星级交互：
  - 未选择星级点击 **Submit**：不关闭好评弹框、不上报星级；Toast 提示文案取自配置键 **`q9`**（`/app/v3/category/gory` → `categoryConfig`，其次 `appConfig` 递归；实现：`+[HQEAppConfigHelper resolvedCopyTemplateForKey:defaultTemplate:]`）。
  - **`q9` 缺省文案**：`Please select a rating before clicking Confirm`
- 提交行为：
  - 星级 ≥ 4：调用系统 App Store 评分（`SKStoreReviewController`）
  - 星级 < 4：展示感谢弹框 `HQTProductRatingThankYouDialog`（居中深色卡片、标题 **Success!**、主按钮 **Confirm** + 箭头），确认后返回上一页

## 13.5.1 文案配置键（category/gory）

| 键 | 场景 | 缺省英文 |
|----|------|----------|
| **q9** | 好评引导未选星点 Submit | `Please select a rating before clicking Confirm` |

查找顺序与项目其它文案键一致：`categoryConfig` → `appConfig` → 上表缺省值。

## 13.6 防连点（质量要求）
- 好评弹框的星级选择可多次点击，但提交按钮须防止连续触发（避免重复 onRating 回调）。

## 13.7 已实现功能点（开发必须保留）
- 好评弹框 `HQTProductRatingGuideDialog`（`HQTBaseDialog` 居中）：
  - 深色卡片 + `tk_bg` 底图 + 右上角 `ic_Icon／X` 关闭；
  - 星级条置于圆角内嵌面板（SF Symbol `star` / `star.fill`，选中色 `#00F6FF`）；
  - 说明文案左对齐（设计稿英文长文案）；
  - 底部唯一主按钮 **Submit**（胶囊 + `tk_jt` 箭头），**无 Cancel 行按钮**。
- 低星感谢弹框 `HQTProductRatingThankYouDialog`：同套深色居中样式，**Success!** + 感谢文案 + **Confirm**。
- 好评弹框出现后即写“已展示”标记，安装周期内不重复弹出。
- 未选星提交：Toast **q9**，弹框保持展示。
