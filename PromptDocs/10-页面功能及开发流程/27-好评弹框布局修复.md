# 好评弹框布局修复

## 修改概述

修复好评引导弹框的两个显示问题：
1. 弹框不在屏幕中间显示
2. 第一个星星与其他4个星星大小不一致

## 1. 问题分析

### 1.1 弹框不在屏幕中间

**原因**：
- 在 `viewDidLayoutSubviews` 中使用了 `pin.hCenter().vCenter()` 但没有先设置高度
- 导致卡片高度为 0，垂直居中失效

**原代码**：
```swift
cardView.pin.hCenter().vCenter().width(cardW)  // 没有高度
// ... 布局子视图 ...
cardView.pin.height(submitButton.frame.maxY + Metrics.bottomPad)  // 后设置高度
```

**问题**：
- `vCenter()` 在高度为 0 时无法正确居中
- 后续设置高度不会触发重新居中

### 1.2 第一个星星不一致

**原因**：
- 星星按钮没有明确设置大小
- StackView 的 `distribution = .equalSpacing` 只控制间距，不控制子视图大小
- 第一个星星可能使用了默认的图片大小

**原代码**：
```swift
let starSize: CGFloat = 28
// ... 创建按钮 ...
starsStack.pin.below(of: messageLabel).marginTop(Metrics.afterMessage).hCenter().width(starsWidth).height(starSize)
```

**问题**：
- 没有为每个按钮设置固定大小
- 依赖图片的固有大小，可能不一致

## 2. 修复方案

### 2.1 修复弹框居中

**文件**：`HQTeConsmpton/Home/HQTProductApplyViewController.swift`

**类**：`HQTRatingGuidanceViewController`

**方法**：`viewDidLayoutSubviews()`

**修复逻辑**：
1. 先布局所有子视图
2. 计算卡片总高度
3. 最后设置卡片的宽度、高度和居中位置

**修复后代码**：
```swift
override func viewDidLayoutSubviews() {
    super.viewDidLayoutSubviews()
    dimView.pin.all()
    
    let cardW = min(Metrics.cardMaxWidth, view.bounds.width - Metrics.cardSideInset * 2)
    
    // 先布局所有子视图以计算卡片高度
    iconView.pin.top(Metrics.iconTop).hCenter().size(Metrics.iconSize)
    titleLabel.pin.below(of: iconView).marginTop(Metrics.afterIcon).horizontally(Metrics.padH).sizeToFit(.width)
    messageLabel.pin.below(of: titleLabel).marginTop(Metrics.afterTitle).horizontally(Metrics.padH).sizeToFit(.width)
    
    // 星星居中布局 - 确保所有星星大小一致
    let starSize: CGFloat = 40
    let starSpacing: CGFloat = 8
    let starsWidth = starSize * 5 + starSpacing * 4
    
    // 设置每个星星按钮的大小
    for case let b as UIButton in starsStack.arrangedSubviews {
        b.pin.size(starSize)
    }
    
    starsStack.pin.below(of: messageLabel).marginTop(Metrics.afterMessage).hCenter().width(starsWidth).height(starSize)
    
    let btnTop = starsStack.frame.maxY + Metrics.starsToButtons
    let btnW = (cardW - Metrics.padH * 2 - Metrics.buttonGap) / 2
    cancelButton.pin.left(Metrics.padH).top(btnTop).width(btnW).height(Metrics.buttonHeight)
    submitButton.pin.after(of: cancelButton, aligned: .top).marginLeft(Metrics.buttonGap).width(btnW).height(Metrics.buttonHeight)
    
    // 设置卡片高度并居中
    let cardH = submitButton.frame.maxY + Metrics.bottomPad
    cardView.pin.hCenter().vCenter().width(cardW).height(cardH)
}
```

### 2.2 修复星星大小一致性

**关键改动**：
1. 增大星星大小：`28` → `40`
2. 减小星星间距：`14` → `8`
3. 为每个星星按钮设置固定大小

**代码**：
```swift
// 设置每个星星按钮的大小
for case let b as UIButton in starsStack.arrangedSubviews {
    b.pin.size(starSize)
}
```

**说明**：
- 使用 `pin.size(starSize)` 为每个按钮设置固定大小
- 确保所有星星大小完全一致
- 不依赖图片的固有大小

## 5. 布局流程

### 5.1 正确的布局顺序

```
1. 布局蒙层（全屏）
   ↓
2. 布局图标（顶部居中）
   ↓
3. 布局标题（图标下方）
   ↓
4. 布局消息（标题下方）
   ↓
5. 设置每个星星按钮的大小
   ↓
6. 布局星星容器（消息下方，居中）
   ↓
7. 布局按钮（星星下方）
   ↓
8. 计算卡片总高度
   ↓
9. 设置卡片位置和大小（居中）
```

### 5.2 关键点

**先计算高度，再居中**：
```swift
// ❌ 错误：先居中，后设置高度
cardView.pin.hCenter().vCenter().width(cardW)
// ... 布局子视图 ...
cardView.pin.height(cardH)

// ✅ 正确：先布局子视图，计算高度，最后居中
// ... 布局子视图 ...
let cardH = submitButton.frame.maxY + Metrics.bottomPad
cardView.pin.hCenter().vCenter().width(cardW).height(cardH)
```

**为每个子视图设置固定大小**：
```swift
// ❌ 错误：依赖图片固有大小
starsStack.pin.width(starsWidth).height(starSize)

// ✅ 正确：明确设置每个按钮大小
for case let b as UIButton in starsStack.arrangedSubviews {
    b.pin.size(starSize)
}
starsStack.pin.width(starsWidth).height(starSize)
```

## 7. 注意事项

### 7.1 PinLayout 使用

**关键原则**：
- 先布局子视图，后布局父视图
- 先计算尺寸，后设置位置
- 使用 `pin.size()` 明确设置大小

**常见错误**：
```swift
// ❌ 错误：先设置位置，后计算大小
view.pin.center()
view.pin.height(calculatedHeight)

// ✅ 正确：先计算大小，后设置位置
view.pin.height(calculatedHeight)
view.pin.center()
```

### 7.2 StackView 子视图大小

**问题**：
- StackView 的 `distribution` 属性不控制子视图大小
- 需要手动为每个子视图设置大小

**解决方案**：
```swift
// 为每个子视图设置固定大小
for subview in stackView.arrangedSubviews {
    subview.pin.size(fixedSize)
}
```

- `star_s@2x.png` 和 `star_s@3x.png`（选中）
