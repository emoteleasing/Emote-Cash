# 07. 订单详情（Order detail）与待提现详情（Withdrawal detail）

## 7.1 页面目标
- 展示订单关键财务信息、费用明细、到期与还款信息。
- 根据订单状态提供对应的底部操作入口（提交/还款/展期/更换银行卡等）。
- 在部分场景提供复借入口（fjtip 开关开启时）。

## 7.2 核心接口

### 普通订单详情：`/app/v3/order/detailV2`
- signed：`orderId`
- unsigned：`productId`（可选；产品入口时约定 `orderId="1"` 进入）
- 响应关键字段（用于 UI）：
  - 产品信息：`productName/productLogo`
  - 订单状态：`orderStatus`
  - 借款金额：`loanAmount`
  - 到期信息：`dueDate` / `dueTime` 等价字段
  - 期限文案：`showTerm`（用于 Loan term 显示）
  - 费用：`feeAmount`（服务费）、`taxAmount`（利息/税费）、`receiptAmount`（到账金额兜底）
  - 时间：申请时间 applyDate、放款时间 payoutDate/disbursementDate 等
  - 还款区字段：`penaltyAmount/totalRepaymentAmount/reductionAmount/alreadyRepaymentAmount/shouldRepaymentAmount/repaymentDate`
  - 银行卡对象：`bankCard`（直接展示接口返回的内容结构）

### 待提现详情：`/app/v3/order/withdrawn/detail`
- signed：`orderId`
- unsigned：`productId`（可选）
- 展示逻辑与普通详情相同，但底部操作与状态驱动不同。

### 7.2.1 页面拆分约束（强制）
- 普通订单详情与待提现订单详情必须是**两个页面类**，禁止业务层通过同一个页面实例混传模式开关。
- 推荐路由：
  - 普通详情页：`HQTOrderDetailViewController` → `/app/v3/order/detailV2`
  - 待提现详情页：`HQTWithdrawOrderDetailViewController` → `/app/v3/order/withdrawn/detail`
- 入口映射：
  - 首页产品/下单后的详情跳转统一进入普通详情页
  - 待提现弹框、订单列表 `status=32` 跳转统一进入待提现详情页

### 7.2.2 待提现页金额与期限（实现口径）
- 金额区（蓝色卡片）对齐产品下单页：
  - 多额度：标题 `Please select loan amount manually(₱)`，展示 `+/-`
  - 单额度：标题 `Loan amount(₱)`，隐藏 `+/-`
  - 金额切换时重置并联动期限、费用明细、还款计划展示
- 额度来源：优先 `amountDetailList/amount_detail_list`；无列表时降级为当前订单单额度。
- 期限来源：优先 `termDetailList/term_detail_list`，再兜底 `productTermItemList/product_term_item_list`。
- 期限交互：
  - 仅多期限时展示下拉箭头并可点击期限行弹出选择器
  - 选项文案口径与下单页一致：优先 `showTerm/show_term`，空值使用 `Option n`，最终按 `loanTenureText` 规则标准化
- 银行卡展示：
  - 有卡则展示整行，无卡隐藏整行
  - 卡信息同时兼容 `bankCard` 与 `bankCardList/bank_card_list` 返回结构

## 7.3 UI 费用说明行（浮层行）
- 费用三行标题与浮层文案统一：
  - Amount received
  - Service fee
  - Interest
- 点击展开规则：
  - 展开浮层叠加在当前行下方，不增加行高
  - 同一页面全局互斥：一次只展开一条
  - 支持点击标题或说明区域收起

## 7.3.1 详情字段显隐判断（按状态）
- 通用展示集合：
  - `30,31,50,36,10,32,99,60,70,61`
- 明细行判断建议：
  - Loan amount：通用展示集合内展示
  - Due date：通用展示集合内展示；无值显示 `—`
  - Loan term：通用展示集合内展示（`showTerm + days` 口径）
  - Service fee / Interest due / Amount received：通用展示集合内展示
  - Date of application：`30,31,50,36,10,32,99`，且已放款时可隐藏
  - Payment date：`60,70,61` 且有放款时间时展示
  - Late charge：仅 `61` 且逾期费 > 0 时展示
  - Total repayment：`60,70,61`
  - Amount of deduction：`60,70,61` 且减免 > 0 时展示
  - Amount repaid：`60,70,61` 且已还 > 0 时展示
  - Amount due：`60,61` 且应还 > 0 时展示
  - Repayment date：`70`（结清）时展示
- 还款区整体：
  - 未放款时可整块隐藏

## 7.4 状态驱动底部按钮（验收点）
- `orderStatus == 36`：
  - 按钮：Change bank account
  - 点击：进入银行卡编辑页（携带 bankCardBindId 兼容字段）
- `orderStatus == 10`：
  - 按钮：Submit
  - 点击：进入抓取流程（设备 + 通讯录分片 + ready）
- `orderStatus == 60`：
  - 按钮：Repay 与 Defer
  - 点击：先请求对应还款/展期接口获取跳转链接，再打开 Web 页面
- `orderStatus == 61`：
  - 按钮：Repay
  - 点击：先请求还款接口获取跳转链接，再打开 Web 页面

### 7.4.1 订单动作接口补充
- 还款：`/app/v3/order/repay/connect`
- 展期：`/app/v3/order/repay/extension`
- 共同规则：
  - signed 带 `orderId`
  - 成功后从返回中提取 `href/url` 并打开 Web
  - Web 页面需实现 `WKNavigationDelegate.decidePolicyFor navigationAction`：
    - `http/https` 链接：`decisionHandler(.allow)`
    - 非 `http` 链接：调用 `UIApplication.shared.open`
    - 若拉起失败：toast 提示 `Please install the app first.`
    - 对非 `http` 链接：`decisionHandler(.cancel)`

### 7.4.2 待提现「Withdraw」按钮动作（强制）
- 仅待提现详情页（`orderStatus == 32`）触发，普通详情页不得复用该提交动作。
- 接口：`/app/v3/order/apply/withdrawal`
  - signed（参与签名，必传）：`orderId`
  - unsigned（不参与签名，按需传入 `data`）：`loanAmount`、`loanTerm`
- 参数口径：
  - `loanAmount`：当前选中额度的借款金额（去掉 `₱` 与千分位逗号后的纯数字字符串；**UI 展示**须用 **`HQTAmountFormatter`**，见 §00.7.1）
  - `loanTerm`：优先 `loanTerm/loan_term`，无值时降级 `showTerm/show_term`
- 防重与状态：
  - 点击后需防连点（锁 + 按钮禁用），请求结束恢复按钮可点击
  - 失败展示 toast（优先接口返回文案）

### 7.4.3 提现成功弹框（UI 与交互）
- 提现接口成功后展示项目统一通用弹框（`showCardAlert` 风格，保持与项目其它弹框一致）。
- 弹框内容：
  - 图标：`make_pic_su`
  - 标题：`Success!`
  - 文案：`Withdrawal is successful, the funds will be transferred to your bank account, please check`
  - 按钮：`Confirm`
- 交互规则：
  - 点击 `Confirm` 返回上一页（`popViewController`）
  - 返回后上一页需刷新数据（通过 `viewWillAppear` 重拉或显式回调刷新，二选一但必须生效）

## 7.5 复借入口（ee3 补充）
- 触发条件：复借引导配置 fjtip 为 on
- 候选筛选：拉取复借候选，筛选 amountDetailList.userType == 2
- 弹框：HQEReloanDialog，文案取对应 key（ee3）
- Apply 后：
  - 拉取 termV3
  - 选择最高金额 + 最低期限
  - 走复借下单并复用订单详情已有“抓取 + 成功/好评链路”
