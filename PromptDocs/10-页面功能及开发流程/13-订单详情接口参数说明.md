# 订单详情接口参数说明

## 概述

本文档说明订单详情相关接口的参数配置，特别是 `appType` 参数的使用。

---

## 接口列表

### 1. `/app/v3/order/detailV2` - 订单详情

**用途**：获取普通订单的详细信息

**调用位置**：`HQTeConsmpton/Order/HQTOrderDetailPlaceholderViewController.swift`

#### 请求参数

**签名参数（signedData）**：
```swift
{
    "orderId": "订单ID"
}
```

**非签名参数（unsignedData）**：
```swift
{
    "productId": "产品ID（可选）",
    "appType": "DC"  // 固定值，标识应用类型
}
```

#### 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderId | String | ✅ | 订单ID，签名参数 |
| productId | String | ❌ | 产品ID，当有产品上下文时传递 |
| appType | String | ✅ | 应用类型标识，固定值 "DC" |

#### 代码实现

```swift
private func fetchDetail() {
    spinner.startAnimating()
    errorLabel.isHidden = true
    let endpoint = isWithdrawDetail ? "/app/v3/order/withdrawn/detail" : "/app/v3/order/detailV2"
    var unsigned: [String: Any] = [:]
    if !productId.isEmpty { unsigned["productId"] = productId }
    
    // 为 detailV2 接口添加 appType 参数
    if !isWithdrawDetail {
        unsigned["appType"] = "DC"
    }
    
    HQTNetworkClient.shared.post(
        endpoint: endpoint,
        signedData: ["orderId": orderId],
        unsignedData: unsigned.isEmpty ? nil : unsigned,
        requireBusinessSuccess: true
    ) { [weak self] result in
        // 处理响应...
    }
}
```

#### 响应数据

```json
{
    "resultCode": 200,
    "resultMsg": "success",
    "data": {
        "product": {
            "productId": "产品ID",
            "productName": "产品名称",
            "productLogo": "产品Logo URL"
        },
        "bankCard": {
            "bankName": "银行名称",
            "bankAccount": "银行账号"
        },
        "bankCardList": [...],
        "orderDetail": {
            "orderId": "订单ID",
            "orderStatus": 订单状态码,
            "loanAmount": "贷款金额",
            "receiptAmount": "到账金额",
            "repaymentAmount": "还款金额",
            "dueDate": "到期日期"
        }
    }
}
```

### 2. `/app/v3/order/withdrawn/detail` - 提现订单详情

**用途**：获取提现订单的详细信息

**调用位置**：`HQTeConsmpton/Order/HQTOrderDetailPlaceholderViewController.swift`

#### 请求参数

**签名参数（signedData）**：
```swift
{
    "orderId": "订单ID"
}
```

**非签名参数（unsignedData）**：
```swift
{
    "productId": "产品ID（可选）"
}
```

**注意**：提现订单详情接口**不需要**传递 `appType` 参数。

---

## appType 参数说明

### 用途

`appType` 参数用于标识应用类型，帮助服务端区分不同的客户端应用。

### 取值

- **"DC"**：当前项目的应用类型标识

### 使用场景

| 接口 | 是否需要 appType | 说明 |
|------|-----------------|------|
| `/app/v3/order/detailV2` | ✅ 是 | 普通订单详情 |
| `/app/v3/order/withdrawn/detail` | ❌ 否 | 提现订单详情 |

### 实现逻辑

```swift
// 为 detailV2 接口添加 appType 参数
if !isWithdrawDetail {
    unsigned["appType"] = "DC"
}
```

**判断条件**：
- `isWithdrawDetail = false`：普通订单，使用 `detailV2` 接口，添加 `appType`
- `isWithdrawDetail = true`：提现订单，使用 `withdrawn/detail` 接口，不添加 `appType`

## 注意事项

### 1. 参数顺序

参数的添加顺序：
1. 先添加 `productId`（如果有）
2. 再添加 `appType`（仅 detailV2 接口）

```swift
var unsigned: [String: Any] = [:]
if !productId.isEmpty { unsigned["productId"] = productId }

// 为 detailV2 接口添加 appType 参数
if !isWithdrawDetail {
    unsigned["appType"] = "DC"
}
```

### 2. 空参数处理

当 `unsigned` 字典为空时，传递 `nil`：

```swift
unsignedData: unsigned.isEmpty ? nil : unsigned
```

这样可以避免发送空对象 `{}`。

### 3. 接口区分

通过 `isWithdrawDetail` 标志区分两种订单类型：

```swift
let endpoint = isWithdrawDetail 
    ? "/app/v3/order/withdrawn/detail" 
    : "/app/v3/order/detailV2"
```

### 4. appType 固定值

`appType` 的值固定为 `"DC"`，不要使用变量或配置：

```swift
// ✅ 正确
unsigned["appType"] = "DC"

// ❌ 错误
unsigned["appType"] = someVariable
```
