# 简易工作流：设计图 + 最少配置，一步一步开发

与 **Prompts参考** 中的简易工作流一致；路径指向本目录 **PromptDocs/PromptDocs**。

只做三件事：

1. **填一次** [项目配置.txt](./项目配置.txt)  
2. **把设计图路径**写进 [页面设计图.txt](./页面设计图.txt)（或在你本地单独维护设计图文件夹，在 txt 里写路径） 
3. **按** [开发顺序.md](./开发顺序.md) 一步一步做：每步打开对应 **Prompt模板-直接使用.md**，填好配置和设计图路径，发给 AI  

---

## 你要维护的东西

| 东西 | 位置 | 说明 |
|------|------|------|
| 项目配置 | `项目配置.txt` | 架构、布局、四个工具类名，**只填一次** |
| 设计图 | `页面设计图.txt` | 每行：`模块 key = Figma/图片路径`（key 与开发顺序表一致） |
| 做哪一步 | `开发顺序.md` | 按表顺序做，做完一步打勾再下一步 |

---

## 第一步：项目配置（只做一次）

打开 `项目配置.txt`，按项目实际情况填写（没有则「无」，HUD 必填）：

```
架构模式=MVVM
布局方式= Masonry
布局工具类= Masonry
HUD工具类= MBProgressHUD
网络请求工具类= AFNetworking
网络图片展示工具类= SDWebImage
```

以后每步从该文件复制到 Prompt 占位符。

---

## 第二步：设计图

- 在 `页面设计图.txt` 里为每个模块写一行，例如：  
  `登录 = https://www.figma.com/design/.../login`  
- 路径可以是相对路径、绝对路径或 Figma 链接。

做某一页时，用该行内容填入 Prompt 里的 `{页面设计图链接或图片路径}`。

---

## 第三步：按开发顺序执行

1. 打开 `开发顺序.md`，确认当前步骤对应的 **Prompt 文件路径**。  
2. 打开该 **Prompt模板-直接使用.md**，在「Prompt 内容」中：  
   - 所有 `{架构模式}`、`{布局方式}`、`{xxx工具类名称}` 等 → 来自 `项目配置.txt`  
   - `{页面设计图链接或图片路径}` → 来自 `页面设计图.txt` 当前模块 key  
3. 将整段发给 AI；建议在 Cursor 中同时 `@` 引用同目录 **需求文档** `NN-xxx.md`。  
4. 接入工程并验证后，在 `开发顺序.md` 给该步打勾。

---

## 小结

| 你要做的 | 怎么拿到 |
|----------|----------|
| 架构、布局、工具类占位符 | 从 `项目配置.txt` 复制 |
| 当前页设计图 | 从 `页面设计图.txt` 按 key 复制 |
| 用哪个 Prompt | `开发顺序.md` 当前行对应的 `…Prompt模板-直接使用.md` |

---

## 与 Prompts参考 的差异

- **Prompts参考**：按功能分子目录（如 `首页/`、`KYC/Pan/`），每目录内一套模板。  
- **PromptDocs**：页面规格集中在 `10-页面功能及开发流程/`，文件名为 `NN-名称.md` + `NN-名称-Prompt模板-直接使用.md`，**工作流相同**。
